# Adopt uv Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pyproject.toml` plus a committed `uv.lock` (Python 3.13) replace `requirements.txt`, and every CI job installs from that lock with uv.

**Architecture:** A uv "virtual" project (`package = false`) whose runtime dependencies are today's `requirements.txt` carried over verbatim, an `mysql` extra, and a `dev` dependency group. The four workflows that run Python switch from `setup-python` + `pip` to `astral-sh/setup-uv` + `uv sync --locked`. No application code changes.

**Tech Stack:** uv, `pyproject.toml` / `uv.lock`, GitHub Actions YAML, Django test runner against MariaDB.

**Spec:** `docs/superpowers/specs/2026-10-27-uv-adoption-design.md`
